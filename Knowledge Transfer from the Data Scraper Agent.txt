## Question schema

Each record in `questions.json` includes:

- `id`
- `subject`
- `paper_number`, `paper_name`
- `attempt`, `exam_year`
- `question_number`, `question_part`
- `question_kind` (`mcq` or `descriptive`)
- `question_text`
- `suggested_answer`
- `marks` when reliably available
- `has_or_alternative`
- source metadata: PDF, ICAI URL, extracted filename, page range
- parser confidence/warnings

MCQ records include the official answer key in `suggested_answer`.

## Important data-handling rules

- Display the source wording exactly; do not rewrite ICAI questions or answers.
- Treat individual suggested-answer PDFs as authoritative.
- Group compilations are not question sources for the first version.
- Some complex descriptive questions intentionally remain one complete parent record when nested `(a)/(b)` labels are ambiguous. This is safer than attaching an answer to the wrong subpart.
- `has_or_alternative: true` means the question contains an `OR` option. Preserve that in the UI.
- Marks are not populated for every record, so the UI must handle missing marks gracefully.
- Examiner remarks are independent study feedback; do not claim a remark maps to a question unless `paper_number`, `question_number`, and `question_part` are present.
